# Purrfect Romance (Cute Cat Doodle Stickers) Template Assets

Collection of 10 adorable die-cut sticker, washi tape, and feline doodle vector SVG assets created specifically for the **Purrfect Romance (Cute Cat Doodle Stickers)** template (`painted-cats`).

- Calico Orange & Warm Coral: `#D97736`, `#FB923C`, `#EA580C`
- Soft Kitten Cream & Ivory: `#FAF6EE`, `#FED7AA`, `#FFF7ED`
- Pastel Pink & Blushing Cheeks: `#F472B6`, `#EC4899`, `#FDA4AF`
