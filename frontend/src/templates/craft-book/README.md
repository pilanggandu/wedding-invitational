# Craft Scrapbook (Handcrafted Book View)

Template undangan pernikahan interaktif berformat **buku album scrapbook (Book View)** dengan inspirasi desain dari craft scrapbook memo dan washi tape (folder `BIRTHDAY_28TH`).

## Fitur Utama

1. **Book View dengan Tab Pembatas Washi Tape**:
   - 7 halaman terstruktur dalam 1 buku:
     1. **Sampul**: Par avion airmail, sobekan kertas kraft hero, foto polaroid dan wax seal monogram.
     2. **Mempelai**: Biodata mempelai pria & wanita dalam kartu polaroid berselotip.
     3. **Acara**: Format tiket penerbangan (*Boarding Pass / Train Ticket*) dengan garis putus-putus dan tombol Google Maps + Tambah ke Kalender.
     4. **Kisah Kita**: Alur cinta dalam kumpulan sticky note warna-warni (*yellow, sage, terracotta, kraft*).
     5. **Galeri**: Foto polaroid tempel dengan kemiringan artistik alami dan pin selotip washi tape.
     6. **Amplop Kado**: Amplop kraft buka-tutup interaktif untuk menyalin nomor rekening dan alamat kado.
     7. **Papan Doa & RSVP**: Papan doa tempel memo dengan pin thumbtack serta formulir konfirmasi kehadiran.

2. **Navigasi Buku Lengkap**:
   - Tab atas berselotip washi tape untuk berpindah bab secara instan.
   - Bar navigasi bawah untuk membuka lembar berikutnya atau kembali ke lembar sebelumnya.
   - Dukungan navigasi keyboard panah kiri (`←`) dan panah kanan (`→`).

3. **Motion Meriah & Aksesibilitas**:
   - Pesta konfeti ganda saat membuka sampul undangan dan mengirimkan doa restu.
   - Menghormati pengaturan `prefers-reduced-motion` dan tombol audio terintegrasi.
